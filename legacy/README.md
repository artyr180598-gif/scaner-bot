# legacy/ — код предыдущего поколения бота (не используется)

Здесь лежит **старый** бот целиком, как он был до полной переработки
(сессия «v5 ADVISOR», 2026-09-02). Ничего из этой папки не импортируется
новым кодом (`app/`) и не запускается.

| Было | Что это |
|---|---|
| `scanner.py`, `strategy.py`, `config.py`, `telegram_bot.py` | ядро v2/v3: сканер арбитражных связок «спот ↔ перпетуал» (MEXC/Bybit/OKX/Binance) и квантовый движок CARRY/REVERSION |
| `directional*.py`, `indicators.py`, `market_data.py`, `setups.py`, `signal_history.py` | ядро v4: направленные Long/Short сигналы по свечам |
| `check_connection.py` | диагностика подключения к биржам |
| `test_*.py` | 165 тестов старого ядра (запускаются только внутри этой папки, см. ниже) |

## Зачем оставлено

1. `backtest/` (в корне) импортирует `strategy.py` и `directional.py` — старые
   бектесты остаются воспроизводимыми:
   ```bash
   PYTHONPATH=legacy .venv/bin/python backtest/run_directional_backtest.py --coins BTC,ETH --bars 2000
   ```
2. В `AI_AGENTS/BRAIN.md` зафиксированы выводы, полученные на этом коде
   (например: «уверенность не предсказывает прибыль», «факторы нельзя считать
   независимыми голосами»). Новое ядро построено с учётом этих уроков, и
   сверяться с первоисточником иногда полезно.
3. Арбитражное ядро — отдельный работающий продукт; удалять его без запроса
   владельца неправильно.

## Как запустить старые тесты

```bash
cd legacy && PYTHONPATH=. ../.venv/bin/python -m unittest discover -p 'test_*.py'
```
