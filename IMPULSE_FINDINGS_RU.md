# Результаты раннего импульса и RID-гипотезы — 5 сентября 2026

## Решение

Не переводить эксперимент в автоматические торговые рекомендации. Более ранний
момент обнаружения не доказал положительного ожидания. Точная стратегия RID не
восстановлена: проверен наш собственный вариант по мотивам видимых инструментов.

## Данные и правила

Binance USD-M, DOGEUSDT, WIFUSDT, 1000PEPEUSDT; июль и август 2026.
267 840 минутных свечей, агрегированных в 5 минут, и доступные архивы глубины
стакана. Это не текущие исполнения Bybit и не проверка всех монет.

Детектор использует исходные пороги из IMPULSE_RESEARCH.md без подбора по прибыли.
Вход моделируется через минуту после закрытия сигнальной свечи по открытию
минутной свечи; отдалившаяся от границы цена отклоняется тем же детектором.
Стоп и тейк по 1%, удержание максимум 120 минут. При касании обоих уровней
на одной минуте первым считается стоп; гэп за стоп исполняется по худшей цене
открытия. Комиссии и проскальзывание заданы суммарно 6 bps на сторону, стресс
12 bps; финансирование — условные 1 bp за 8 часов, не историческая ставка.
Спред не восстановлен отдельно; модель издержек не гарантирует реальную цену.
Без плеча, мартингейла и одновременных позиций по одной монете внутри модели.

RID-гипотеза дополнительно требует пять последовательных минут с долей bid
в глубине ±0,2% не менее 60% для LONG (не более 40% для SHORT), а также долю
исполненных taker-покупок за 5 минут не менее 55% (не более 45% для SHORT).
Это агрегированная глубина и поток исполнений, НЕ реконструкция тепловой карты
конкретных заявок и не доказательство поглощения. Последний используемый снимок
стакана должен предшествовать границе свечи минимум на 5 секунд и быть не старше
90 секунд. Фильтр фиксируется на момент сигнала, не обновляется при исполнении.

## Итоги после базовых издержек

| Вариант | Сделок | Средний результат | Доля прибыльных |
|---|---:|---:|---:|
| Первый 5m-пробой | 95 | −0,1227% | 44,21% |
| Первый пробой + глубина + taker-поток | 1 | +0,0494% | Статистически неинформативно |

При стрессовых издержках средние результаты соответственно −0,2427% и −0,0707%.
Для первого пробоя: июль 52 сделки, −0,1878%; август 43 сделки, −0,0440%.
По монетам: DOGE 32 сделки, −0,2111%; WIF 25, −0,0426%; PEPE 38, −0,1010%.
Проценты от начального номинала позиции, не доходность депозита. Медианное
удержание первого варианта 120 минут; больше половины сделок завершились по
времени. Значит проверенная формула не обеспечила ожидаемого быстрого движения
к цели 1% в большинстве случаев.

Один положительный случай RID-варианта НЕ подтверждает успех. Нулевой разброс
bootstrap на одном наблюдении математически неизбежен и не является уверенностью.
Месяцы уже использовались в предыдущих исследованиях: это повторная исследовательская
выборка, НЕ нетронутый контроль. Нельзя продолжать перебирать варианты на ней и
выдавать найденный плюс за независимое доказательство.

## Воспроизведение

Из корня репозитория, в окружении с установленными зависимостями проекта:

```sh
python rid_depth_download.py
PYTHONPATH=. python scripts/impulse_study.py
python -m pytest -q
```

Загрузчик получает публичные архивы data.binance.vision, требует сети и места.
Результаты по каждой сделке: impulse_study_results.json. Bootstrap группируется
по UTC-дню, а не отдельным сделкам. История до сигнала не содержит будущих свечей.

22 теста проекта прошли ранее, включая технические проверки нового детектора.
Эти тесты не заменяют независимую проверку бэктеста. На этом этапе новая модель
не объединена с main и не развёрнута. Рабочая стратегия бота не изменена.
