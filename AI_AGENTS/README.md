# 🧠 AI_AGENTS — «мозг» проекта для ИИ-агентов

Эта папка — **живая память** репозитория `scaner-bot`. Любой новый агент
(или человек) должен прочитать её ПЕРЕД тем, как менять код: здесь записано,
что уже сделано, что работает, что не работает и почему, какие ошибки уже
совершались, чтобы не повторять их.

## Карта файлов

| Файл | Что внутри | Когда читать |
|---|---|---|
| [`BRAIN.md`](BRAIN.md) | **Текущее состояние**: что работает, что сломано, что удалено, открытые вопросы | ВСЕГДА первым |
| [`BACKTESTS.md`](BACKTESTS.md) | Журнал всех прогонов бектеста: данные, параметры, метрики, вердикты | Перед изменением стратегии/параметров |
| [`DATA_SOURCES.md`](DATA_SOURCES.md) | Где взять реальные исторические данные; сетевые ограничения среды; проверенные и мёртвые пути | Перед запуском бектеста / скачиванием данных |
| [`DECISIONS.md`](DECISIONS.md) | Архитектурные решения (ADR): почему движок такой, цифры и аргументы | Перед рефакторингом стратегии |
| [`PLAYBOOK.md`](PLAYBOOK.md) | Пошаговые инструкции: тесты, бектест, типичные грабли | Перед любой работой с кодом |

## Правила для агентов (коротко)

1. **Прочитай BRAIN.md** — не делай того, что уже провалилось (список ниже).
2. **Не ломай принципы честности бектеста** (смотреть в будущее, «оптимизировать»
   комиссию) — иначе получишь красивую кривую, которая умрёт на реале.
3. **Изменил стратегию → прогони бектест и запиши результат в BACKTESTS.md**,
   включая отрицательный («не помогло» — тоже результат).
4. **Изменил код → все 118 тестов должны быть зелёными**:
   `.venv/bin/python -m unittest discover -s tests`
5. **Обнови BRAIN.md** в конце работы: что сделал, что сломалось, что осталось.
6. Данные бектеста (`backtest/data_cache/`) и отчёты `.json` — НЕ коммитить
   (gitignore уже настроен). Отчёты `.md` в `backtest/results/` — коммитить.

## TL;DR текущего состояния (обновлено: 2026-08-30)

- Стратегия v3 (двухклассовая: CARRY + REVERSION) — **работает и подтверждена
  бектестом на 4.5 годах реальных данных**: PF 3.33, winrate 71%, maxDD 1.29%,
  1269 сделок (старый порог v2 давал 68 за тот же период).
- Старый плоский порог `MIN_SPREAD_PERCENT=2%` — **подтверждённая проблема**:
  почти не срабатывает на ликвидных парах. Оставлен как режим `fixed`.
- Комиссии в сигналах v2 считали только вход — **занижали издержки вдвое**;
  v3 считает round-trip. Не откатывать.
- Прямой доступ к API бирж из песочницы Arena **заблокирован**; данные для
  бектеста берутся с GitHub (см. DATA_SOURCES.md).
