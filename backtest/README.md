# Бектест спот↔перп арбитража (v3)

Честный офлайн-бектестер квантового ядра на **реальных исторических данных**
(Binance спот 1ч/1д + USDT-M перп 4ч/1д + funding 8ч, 2019→сейчас, ~50 монет).

## Принципы честности (нарушать нельзя)

1. **Один и тот же код сигнала** — `backtest/engine.py` импортирует
   `strategy.SignalEngine` из корня проекта. Бектест проверяет ровно ту
   логику, что работает в живом сканере. Никаких «симуляционных» копий.
2. **Никакого заглядывания в будущее**: сигнал считается по закрытию бара `t`,
   исполнение — по OPEN бара `t+1` (и на вход, и на выход).
3. **Комиссии taker на обе ноги и на вход, и на выход** (round-trip ≈ 0.30%).
4. **Проскальзывание** на каждую ногу (эмуляция half-spread стакана, bps).
5. **Funding начисляется по реальным историческим ставкам** в моменты выплат
   между входом и выходом (со знаком позиции).
6. **PnL считается точно по обеим ногам**, не приближённо «спред минус fee».

## Как запустить

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt -r backtest/requirements.txt

./backtest/fetch_data.sh                      # ~600 МБ сырых CSV (sparse clone GitHub)
.venv/bin/python backtest/prepare_data.py --prune-raw   # компактный кеш ~40-70 МБ

.venv/bin/python backtest/run_backtest.py                 # весь период
.venv/bin/python backtest/run_backtest.py --years 2       # последние 2 года
.venv/bin/python backtest/run_backtest.py --slippage-bps 10 --tag stress   # стресс
```

Отчёт: печать + `backtest/results/<tag>.md` (коммитим как историю) и
`.json` (не коммитим). Журнал всех прогонов и выводы — в
`AI_AGENTS/BACKTESTS.md`.

## Стратегии в сравнении

| Имя | Суть |
|---|---|
| `OLD` | Плоский порог v2 (вход при NET ≥ 2%) — как старый бот |
| `CARRY_NAIVE` | Наивный carry: funding ≥ 0.01%/8ч, без статистики |
| `NEW_CARRYONLY` | v3 только класс CARRY (z-пол + funding edge + round-trip) |
| `NEW_REVONLY` | v3 только класс REVERSION (z-аномалия ≥ 1.5σ, выход на сходимости) |
| `NEW` | v3 целиком: CARRY + REVERSION, каждому классу своя аллокация |

## Итог (2021-11 → 2026-05, 49 монет, все издержки включены)

| стратегия | сделок | winrate | avg pnl | итог | годовые | maxDD | PF |
|---|---|---|---|---|---|---|---|
| OLD (v2) | 68 | 97.1% | +4.68% | +37.2% | 7.2% | 1.52% | 22.0 |
| CARRY_NAIVE | 1254 | 62.0% | +0.20% | +13.4% | 2.8% | 1.16% | 1.9 |
| NEW_CARRYONLY | 1195 | 68.9% | +0.34% | +22.2% | 4.5% | 1.14% | 2.5 |
| NEW_REVONLY | 134 | 80.6% | +1.69% | +25.4% | 5.1% | 1.31% | 9.2 |
| **NEW (v3)** | **1269** | **71.1%** | **+0.48%** | **+43.9%** | **8.3%** | **1.29%** | **3.3** |

При консервативных аллокациях (5% капитала на CARRY-сделку, 10% на REVERSION).
Стресс-тест проскальзыванием 10 bps/ногу (4× базового): NEW сохраняет
+16.9% за 2 года (PF 2.5), наивный carry при этом умирает (PF 0.9) —
вся устойчивость даётся квантовым слоем отбора.

## Направленный слой (PULSE) — отдельно от арбитража

Не путать с таблицей выше. Это **другой продукт**: лонг/шорт самой монеты,
не хедж спот↔перп.

```bash
.venv/bin/python backtest/run_pulse.py --tag pulse-v1
```

Канон: [`results/pulse-v1.md`](results/pulse-v1.md) — 49 монет, 4ч, IS до 2024-05-01 /
OOS после, 26 стратегий (классический TA + crowding + собственные PULSE/NEXUS).

**Итог pulse-v1:** ни одна направленная стратегия не прошла OOS
(PF≥1.20, avg>0, Sharpe>0). Ближайшая — `MOM_WEEKLY` (OOS PF 1.09, Sharpe 0.09).
Автоторговлю направлением **не внедрять**. Команда `/pulse` в боте — только
информационный скоринг. `pulse-smoke.md` (3 монеты) игнорировать.

Свой picker LOW_CHAN: `run_forge3.py` → `results/forge-v3.md` (OOS +37%/год,
Sharpe 0.97, яма −30%). `/forge` — инфо, не авто-вход. v4 overlays (VT/DD)
убивают первую половину OOS — не брать.

## Известные ограничения

* Цена — close/open баров, не стакан: глубина/частичное исполнение не
  моделируются (компенсируется slippage-параметром и чувствительностью).
* Один источник (Binance): межбиржевой спред моделируется косвенно —
  базис спот↔перп. Живой сканер считает реальные кросс-биржевые книги.
* Прошлые результаты не гарантируют будущих.
