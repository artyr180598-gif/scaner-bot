# 🚀 Crypto Scanner Bot — направленные сигналы + арбитраж (v4.0 DIRECTIONAL)

> **v3.0 — квантовое ядро.** Каждая пара держит скользящую историю спреда;
> сигналы двух классов — **CARRY** (сбор funding, удержание дни-недели) и
> **REVERSION** (вход на статистической аномалии спреда по z-score, выход на
> сходимости) — с честной round-trip экономикой (комиссии вход+выход,
> проскальзывание, funding). Проверено бектестом на 4.5 годах реальных
> данных: **1269 сделок, winrate 71%, Profit Factor 3.33, maxDD 1.29%**
> (старый порог 2% давал бы 68 сделок за тот же период). Детали: `/strategy`
> в боте, `backtest/README.md` и `AI_AGENTS/` в репозитории.

> **v4.0 — направленное ядро.** Кроме рыночно-нейтрального арбитража бот
> теперь отвечает на вопрос «куда пойдёт монета»: **Long / Short / сигнала
> нет** по любой монете биржи, с двумя честными уверенностями (качество
> данных и сходимость факторов), зоной входа, стопом, TP1/TP2/TP3, R/R,
> плечом, размером позиции по риску и объяснением простыми словами.
> Проверено бектестом на реальных данных: **10 345 сделок, win-rate 47.6%,
> Profit Factor 1.02** — то есть примерно безубыточность, а корзина сигналов
> с уверенностью ≥75% оказалась даже ХУЖЕ (PF 0.85). Мы это пишем прямо в
> интерфейсе бота. Подробности: `backtest/results/directional_v4.md`.

Асинхронный сканер арбитражных связок между криптобиржами
(**MEXC, Bybit, OKX, Binance**) с управлением через Telegram.
Фоновый Worker-процесс для **Railway.app** (работает и локально).

## 🔕 Главное изменение в v2.0: никакого спама

**Бот по умолчанию НИЧЕГО не присылает сам.** Он живёт в фоне, держит живые
стаканы (bid/ask) всех монет на всех биржах и выдаёт сигналы **только по
запросу** — в стиле классических manual-сканеров (ArbitrageScanner и подобных):

| Ты делаешь | Бот отвечает |
|---|---|
| `/top` | таблица топ-спредов **в столбиках**: монета, **цены на обеих биржах**, точный разрыв (гросс), NET, **профит со $100**, ликвидность. 🛡 фейковые «миллиардные» спреды (тикер-двойники) отфильтрованы |
| `/signal BTC` | лучшая связка прямо сейчас — детальный разбор с планом действий и funding |
| `/coin BTC` | **все цены BTC на каждой бирже** (спот ask/bid + перп bid/ask), лучшая связка, что делать |
| `/coins` | список всех монет, которые сканируются (по объёму 24ч) |
| `/funding BTC` | funding-рейты по биржам: кто кому платит, APR |
| `/calc BTC 1000` | сколько профита с твоего депозита |
| `/signals` | журнал: где за сессию спред был ≥ порога (без отправки, просто история) |

Если хочешь, чтобы бот сам присылал сигнал при превышении порога —
ставь переменную `SIGNAL_MODE=auto` (с кулдауном на пару и лимитом
сообщений за цикл, как в v1).

## 📡 Как это работает

```
           Живые стаканы (WebSocket, fallback — REST), реальные цены,
           публичные API, БЕЗ API-ключей
    MEXC   Bybit   OKX   Binance
    ┌─────────────────────────────────────────┐
    │  для каждой монеты: спот USDT + перп USDT │
    └─────────────────────────────────────────┘
                      │
                      ▼
   РАСЧЁТ (в фоне, каждые 5 с + по запросу):
   S→F (contango):    NET = (FutBid − SpotAsk)/SpotAsk × 100% − комиссии
   F→S (backwardation): NET = (SpotBid − FutAsk)/FutAsk × 100% − комиссии
   • покупка — на бирже с САМОЙ НИЗКОЙ ценой (ask)
   • продажа/шорт — на бирже с САМОЙ ВЫСОКОЙ ценой (bid)
   • «свежие» данные: котировка старше 45 с (WS) в расчёт не идёт
                      │
                      ▼
   По запросу: HTML-таблицы в Telegram (цены, ликвидность, funding, план)
```

**Схема хеджа.** LONG спот + SHORT перпетуал (или наоборот) = дельта-нейтральная
позиция: цена монеты может лететь куда угодно, P&L от движения ≈ 0, а ты
забираешь запертый спред (+ funding, если он на твоей стороне).

**Точность.** Цены берутся из реальных стаканов (top-of-book) через
[ccxt](https://github.com/ccxt/ccxt) `ccxt.pro`: WebSocket с автоматическим
переключением на REST при сбоях. В сигнал попадают только пары, где обе
стороны (спот ask и перп bid) свежие. Ликвидность в таблице — глубина
лучшей цены; не входи больше неё.

| `/coins [PAGE]` | Список монет, которые сканируются: объём 24ч, на скольких биржах спот/перп, лучший спред. По 20 на страницу |

| `/status` | Аптайм, статистика, свежих стаканов, лучший спред прямо сейчас |

Под каждым сообщением — inline-кнопки того же меню. Команды принимаются

## 📱 Примеры ответов

**`/top` — спред в столбиках:**
```
📊 ТОП-10 СПРЕДОВ ПРЯМО СЕЙЧАС
26.08 18:00 UTC · S→F: купить спот (ask) + шорт перп (bid)

#  МОНЕТА  КУПИТЬ СПОТ         ШОРТ ПЕРП           ГРОСС   NET     Z·ГРЕЙД   С $100  ВХОД МАКС
-  ------  ------------------  ------------------  ------  ------  ---------  ------  ---------
1  BP      MEXC    0.438100    Gate.io 0.482000    +10.02% +9.87%🔥 +3.2σ·A✅ ≤$5!   $5!
2  FUTUON  MEXC    126.5600    Gate.io 130.6200    +3.21%  +3.06%🔥 +2.4σ·B✅ +$3.06 $900
3  HEMI    MEXC    0.00873100  Binance 0.00882300  +1.05%  +0.90%  +1.9σ·B   +$0.90 $900
...
⚠️ Глубины меньше $100 у N из 10 связок — их спред берётся только малой суммой,
на $100 он съедается проскальзыванием. На $100 целиком заходят: FUTUON, HEMI
🏷 КУПИТЬ СПОТ — биржа и цена покупки (ask, где ДЁШЕВО) · ШОРТ ПЕРП — где ДОРОГО (bid)
   ГРОСС = (продажа − покупка) / покупка · NET = ГРОСС − комиссии 0.15%
   С $100 — исполнимый профит с учётом проскальзывания · «≤$X!» — $100 не влезает, максимум $X
   ВХОД МАКС — сколько $ влезает по видимым уровням обеих ног («!» — меньше $100)
🔍 ДЕТАЛЬНЫЙ РАЗБОР ТОП-3: маршрут «где, что, по чём», комиссии, исполнимость
```

**`/coin BTC` — разбор по биржам:**
```
💠 BTC/USDT — РАЗБОР ПО БИРЖАМ

📥 СПОТ USDT — ask = цена покупки (ниже лучше), bid = цена продажи
Биржа     ASK купить   BID продать  Глубина ASK
MEXC      117,234.50 ← 117,233.80   $12,345
Binance   117,240.10   117,239.40   $98,000
...

📤 ПЕРПЕТУАЛЫ USDT — bid = цена шорта (выше лучше), ask = цена лонга
Биржа     BID шорт     ASK лонг     Funding/8ч
Bybit     117,512.00 ← 117,512.80   +0.0100%
OKX       117,490.10   117,490.90   +0.0075%
...

🏆 ЛУЧШАЯ СВЯЗКА S→F · BTC — спот → фьючерс (купить спот / шорт перп)
Параметр           Значение
ПОКУПКА (дёшево)   MEXC   117,234.50
ПРОДАЖА (дорого)   Bybit  117,512.00
разрыв Δ (гросс)   277.5000 = +0.24%
комиссии           −0.15% (спот 0.10% + перп 0.05%)
NET профит         +0.09% ❌ ниже порога
funding            +0.0100%/8ч на Bybit (шорт получает)

📋 ПЛАН ДЕЙСТВИЙ:
1️⃣ Купи BTC на споте MEXC по ~117,234.50 USDT
2️⃣ Одновременно открой SHORT перпетуала Bybit по ~117,512.00 (1x–3x, изолированно)
3️⃣ Хедж зафиксирован: P&L от цены ≈ 0, спред заперт
4️⃣ Выход: продай спот + выкупи шорт, когда спред сошёлся
```

Если у монеты на одной из бирж цена в разы/сотни раз отличается от медианы —
бот помечает её ⚠ («другая монета с тем же тикером») и не строит с ней связки.

**`/signal BTC`** — такой же детальный разбор одной связки + примеры профита
на $100/$1,000/$5,000/$10,000 + «другие возможности» + риски.

## 🚀 Быстрый старт

### Локально
```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
cp .env.example .env            # вписать TELEGRAM_BOT_TOKEN и CHAT_ID
.venv/bin/python check_connection.py   # диагностика: биржи отвечают с твоего IP?
.venv/bin/python main.py
```
Без `TELEGRAM_BOT_TOKEN`/`CHAT_ID` работает DRY-RUN: ответы на команды
печатаются в лог — удобно проверять без Telegram.

### Railway
1. New Project → Deploy from Repository → выбери этот репозиторий.
2. Worker (не Web Service). Start command: `python main.py` (Procfile уже есть).
3. Variables: `TELEGRAM_BOT_TOKEN`, `CHAT_ID` (+ опционально `SIGNAL_MODE=auto`).
4. Напиши боту `/help` — дальше всё кнопками.

### ⚠️ Гео-блокировки (важно для Railway)
Биржи блокируют IP из ряда стран/регионов (Binance — США и др., у Bybit/OKX
свои списки). Railway по умолчанию хостит в США, поэтому **Binance может не
подключиться** — это нормально: бот исключит недоступную биржу и продолжит
работать с остальными (видно в `/status`). Варианты: сменить регион Railway
или задать `HTTPS_PROXY` на рабочий. Диагностика: `python check_connection.py`.

```bash
./backtest/fetch_data.sh && .venv/bin/python backtest/prepare_data.py --prune-raw
.venv/bin/python backtest/run_backtest.py --tag my-run   # отчёт в backtest/results/
```
Итог v3 (арбитраж) на 4.5 годах реальных данных — см. `backtest/README.md` и
`AI_AGENTS/BACKTESTS.md`.

Бектест направленного ядра (те же реальные часовые свечи, 11 монет):
```bash
.venv/bin/python backtest/run_directional_backtest.py \
    --coins BTC,ETH,SOL,BNB,XRP,ADA,DOGE,AVAX,LINK,DOT,ATOM \
    --bars 40000 --step 3 --profile moderate \
    --out backtest/results/directional_moderate.json
```
Отчёт и разбор находок: **`backtest/results/directional_v4.md`**.

## 📝 Честные ограничения

* **Ликвидность** — указана глубина ЛУЧШЕЙ цены. Реальное исполнение на
  большие суммы проседает по стакану: не входи больше ВХОД МАКС из таблицы.
* **Funding** — меняется; при отрицательном (для шорта) он съедает профит.
  Смотри `/funding` перед входом.
* **Переводы** — для S→F переводы не нужны (USDT на обеих биржах заранее);
  для F→S нужен инвентарь монеты на спот-бирже.
* **Направленные сигналы не «печатают деньги».** На истории (10 345 сделок,
  с комиссиями и проскальзыванием) win-rate 47.6%, Profit Factor 1.02 —
  результат около нуля и нестабильный по годам (2022: PF 1.15; 2025: 0.91).
* **Уверенность ≠ вероятность заработать.** По бектесту сигналы с
  уверенностью ≥75% отработали ХУЖЕ (PF 0.85), чем сигналы с уверенностью
  <60% (PF 1.03). Уверенность показывает только, насколько факторы
  согласны между собой.
* **Бектест шёл на 1h-свечах**, а по умолчанию бот настроен на скальп
  (5m/15m/1h/4h) — на этих ТФ поведение не проверено, 5m-истории нет.
  Также не моделировались funding/OI/стакан и частичные фиксации.
* **Бот не торгует** — только находит возможности на публичных данных.
  Решение, исполнение и риск — твои. Это не финансовый совет.
