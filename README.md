# Chris Bots — Telegram-советник по криптовалютам

> **Крис** — аналитическая модель экосистемы Chris Bets. Ищет крипто-активы
> на **зарождении импульса** (до того, как они улетели) и выдаёт сигнал
> только при высокой уверенности (≥ 75% по шкале модели).

## Что внутри

Бот-советник на **aiogram 3 + ccxt (async)**, без API-ключей (только публичные
эндпоинты бирж). Лучшие практики топ-5 open-source проектов:

| Проект        | Что взяли                                                     |
|---------------|----------------------------------------------------------------|
| **Freqtrade** | DataFrame-based индикаторы, `populate_indicators`-стиль, чёткий план сделки |
| **OctoBot**   | Модульная система (groups / tentacles), asyncio-оркестрация |
| **Jesse**     | Clean research workflow, мульти-таймфреймовый контекст        |
| **CryptoSignal** | TA pipeline (informants → analyzers → strategies)            |
| **Nautilus Trader** | Event-driven шина для изоляции модулей                    |

## Запуск

```bash
# 1. Установить зависимости
pip install -r requirements.txt

# 2. Скопировать env и заполнить
cp .env.example .env
# отредактируй TELEGRAM_TOKEN (токен от @BotFather)

# 3. Запустить
python -m chris_bots.main
```

### Как ищется `.env`

Файл подхватывается автоматически при старте — в порядке приоритета:

1. переменные окружения процесса (они всегда важнее файла);
2. путь из `ENV_FILE` (или `DOTENV_PATH`), если задан;
3. `.env.local`, затем `.env` в текущей директории, дальше вверх по дереву
   и рядом с корнем проекта.

В логе старта видно, что именно подхватилось и откуда взят токен:

```
06:52:19 | INFO | chris_bots.main | env file: /path/to/scaner-bot/.env
06:52:19 | INFO | chris_bots.main | chris_bots starting (token из TELEGRAM_TOKEN=12345678…, dry_run=True)
```

### Имя переменной с токеном

Принимаются (по убыванию приоритета):

```
TELEGRAM_TOKEN  >  BOT_TOKEN  >  TELEGRAM_BOT_TOKEN  >  TG_TOKEN  >  BOT_API_TOKEN
```

Это важно для хостингов вроде **Railway / Render / Heroku**: там токен задаётся
переменной платформы, а не файлом `.env`. Если переменная уже заведена под другим
именем из списка — переименовывать её не нужно.

Если токен не найден, бот не стартует и прямо пишет, какие имена ожидает и какие
похожие переменные реально видит в окружении (только имена, значения не печатаются):

```
settings invalid: TELEGRAM_TOKEN is required — ожидается одна из переменных:
TELEGRAM_TOKEN, BOT_TOKEN, TELEGRAM_BOT_TOKEN, TG_TOKEN, BOT_API_TOKEN.
Сейчас в окружении процесса есть похожие переменные: MY_BOT_KEY
(файл .env не найден — беру только переменные окружения процесса).
Токен выдаёт @BotFather. Если на хостинге переменная называется иначе —
переименуйте её в TELEGRAM_TOKEN.
```

Пробелы и кавычки вокруг токена обрезаются автоматически.

## Ключевые принципы

1. **Не гонимся за движением.** Активы, уже улетевшие на ±N% за последние
   `ANTI_CHASE_WINDOW_BARS` баров, отбрасываются.
2. **Жёсткий порог 75% по signal confidence.** Это не «вероятность profit»,
   а мера согласованности групп факторов. **Бэктестер подтвердил**:
   на BTC 1H за 12 дней связь confidence и прибыли обратная или нулевая.
   Поэтому в UI есть явный disclaimer.
3. **Групповая схлопка.** Тренд на 4 ТФ и RSI на 3 ТФ — это одно наблюдение.
   Голоса группируются по семантике (тренд, моментум, объём, …).
4. **Двойная уверенность.** `data confidence` (полнота/свежесть) отдельно от
   `signal confidence` (согласие факторов). Слабые данные → сигнал не выдаётся.
5. **Только публичные эндпоинты бирж.** API-ключи не нужны.

## Бэктестер (честные результаты)

```
=== Backtest: BTC-USDT 1H (300 свечей ≈ 12 дней, OKX) ===
── Гипотеза: «confidence ≥ 75% = прибыль» ──
  <60%     n=39  winrate=38.5%  PF=0.65  PnL=-10.61%
  60-75%   n= 9  winrate=44.4%  PF=0.77  PnL= -1.93%
  ≥75%     n= 0  (стратегия молчит — корректно для боковика)
```

На **синтетике с трендом**: winrate 93.1%, PF 21.25 (стратегия работает).
На **синтетическом боковике**: 0 сигналов (стратегия не лезет где нечего делать).
На **реальном BTC 1H в боковике**: 0 сделок выше 75% (стратегия молчит, как должна).

**Вывод**: на текущем рынке (BTC 1H $77-80k, боковик) бот корректно молчит.
Бэктестер — это **страховка от повторения ошибки v4** (BRAIN.md п.0b):
«уверенность ≥ 75% = прибыль» не подтвердилась, и теперь мы это знаем
честно, а не на словах.

## Что дальше

- **Калибровка** `signal_confidence` на исходах (Platt/isotonic) — чтобы confidence
  хотя бы был **откалиброванной** вероятностью.
- **Альтернативные ТФ** (5m/15m) — на них больше трендовых движений.
- **Альткоины** — там волатильность выше, стратегия может чаще срабатывать.
- **Funding rate + OI** (как в OctoBot «DEX perps») для подтверждения тренда.
- **Calmar ratio** и **Sortino ratio** в BacktestResult (после набора данных).
