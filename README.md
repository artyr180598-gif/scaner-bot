# 🚀 Arbitrage Scanner Bot — Spot/Futures Hedge

Автономный асинхронный сканер арбитражных связок между криптобиржами
(**MEXC, Bybit, Gate.io, OKX, Binance**) с уведомлениями в Telegram.
Проектировался как фоновый Worker-процесс для **Railway.app**.

Логика проста и надёжна: **купить дёшево на споте одной биржи → продать дорого
на фьючерсах (перпетуалах) другой биржи**, оставаясь в хедже (long спот /
short перп). Как только чистый спред превышает порог — бот мгновенно
присылает сообщение в Telegram с деталями сделки.

**Сканируются ВСЕ монеты бирж** (по умолчанию): любая пара, у которой есть
USDT-спот хотя бы на одной бирже и USDT-перпетуал хотя бы на одной —
тысячи инструментов, а не только популярные монеты. Управлять ботом можно
как пассивно (сигналы приходят сами), так и интерактивно — командами и
inline-кнопками прямо в Telegram (раздел «Управление в Telegram» ниже).

> ⚠️ **Дисклеймер.** Сканер — инструмент поиска возможностей, а не гарантия
> прибыли. Реальный результат зависит от комиссий вывода, ставок
> финансирования (funding), проскальзывания при исполнении и минимальных
> лотов. Бот ничего не покупает и не продаёт — он только читает рыночные
> данные и уведомляет.

## 📡 Реальные данные — никаких выдуманных цен

Бот получает **только реальные данные с бирж**:

* Источник — **публичные (public) REST- и WebSocket-эндпоинты** бирж через
  библиотеку [ccxt](https://github.com/ccxt/ccxt) (модуль `ccxt.pro` входит
  в пакет `ccxt`). **API-ключи не нужны и не используются.**
* Цены берутся напрямую из **стаканов (Order Book)**: лучший Ask спота —
  цена покупки, лучший Bid фьючерса — цена продажи. Никаких индикативных
  «последних сделок» и никакой генерации данных внутри кода.
* Каждая котировка имеет метку времени; устаревшие (по умолчанию старше
  45 секунд) в расчёт спреда не попадают.

### Как убедиться, что данные реальные

1. **Командой в Telegram**: отправьте боту `/price BTC` или нажмите кнопку
   «💠 Цена BTC» — в ответ придут реальные bid/ask со стаканов каждой биржи
   с текущего кэша. `/top` покажет актуальные чистые спреды по всем парам.
2. **Логи при старте.** Как только с биржи приходит первый стакан, бот пишет
   в лог строку вида:
   ```
   MEXC spot: поток данных активен — BTC/USDT bid=117,254.12 / ask=117,254.13 ...
   ```
   Это реальные цены, полученные с биржи в этот момент.
3. **Скрипт диагностики** (работает и локально, и на Railway):
   ```bash
   python check_connection.py            # все биржи
   python check_connection.py mexc bybit # только выбранные
   ```
   Опрашивает публичные эндпоинты и печатает живые bid/ask с задержкой в мс.
4. **Периодический статус** в логах (раз в `STATUS_LOG_MINUTES`, по умолчанию
   10 мин): сколько свежих стаканов в кэше, лучший чистый спред прямо сейчас.

## 🎛 Управление в Telegram — профессиональный UX

Бот не только присылает сигналы сам — им можно пользоваться интерактивно.
Под каждым сообщением (сигналы, статусы) есть **inline-кнопки**, а команды
принимаются через long polling (без вебхуков — ничего лишнего для Worker):

| Команда / кнопка | Что делает — максимально понятно |
|---|---|
| `/top` · 📊 Топ спредов | Топ-10 чистых спредов с **ценами покупки/продажи**, ликвидностью, возрастом. Можно `/top 20` |
| `/price BTC` · 💠 Цена | Все цены BTC по биржам (спот ask / фьючерс bid) + **лучшая связка + пошаговый план** |
| `/calc BTC 1000` · 🧮 Калькулятор | Сколько заработаешь с $1000 на BTC: чистый профит, комиссии, примеры на $100-$10000 |
| `/status` · 🩺 Статус | Аптайм, статистика, свежие стаканы, лучший спред, кулдауны |
| `/exchanges` · 🏦 Биржи | Детальный статус каждой биржи: WS/REST, ошибки, свежие стаканы, круг опроса |
| `/guide` · 📚 Гайд | Полный гайд: что такое арбитраж, пошаговое исполнение, риски, советы профи |
| `/strategy` · 🧠 Стратегия | Математика, типы арбитража, funding, как снижать риски, вдохновлено топ-ботами GitHub |
| `/help`, `/start` | Справка по командам — коротко и ясно |

Особенности:
* Команды принимаются **только от чатов из `CHAT_ID`** — посторонние боту не отвечают.
* Ответы на кнопки не зависят от кулдауна: `/top` показывает всё, даже пары в кулдауне.
* Каждая кнопка даёт ответ за доли секунды — данные уже в кэше сканера.

## 🧮 Формула сигнала

```
Гросс-спред  = (Futures_Bid - Spot_Ask) / Spot_Ask × 100
Чистый спред = Гросс-спред - Total_Commissions
             = Гросс-спред - (SPOT_TAKER_FEE + FUTURES_TAKER_FEE)
```

Дефолтные комиссии: **0.1% спот + 0.05% фьючерсы = 0.15%** (настраиваемые).
Сигнал отправляется, только если чистый спред ≥ `MIN_SPREAD_PERCENT`
(по умолчанию **2.0%**).

Пример: спот-ask MEXC = 1.0000, фьючерс-bid Bybit = 1.0300 →
гросс 3.00% − 0.15% = **чистые +2.85%** → сигнал.

### Ключевые решения по надёжности

* **Без API-ключей** — только публичные эндпоинты бирж.
* **Все монеты по умолчанию**: каждая пара «USDT-спот где-то + USDT-перп
  где-то» — пересечения считаются автоматически по рынкам всех бирж;
  WS-подписки используют минимальную глубину стакана (память и трафик).
* **`enableRateLimit: True`** в ccxt + доп. паузы между REST-запросами —
  IP Railway не забанят за частые запросы.
* **WebSocket-first**: подписки `watch_order_book` дают стакан в реальном
  времени; при устойчивых сбоях WS (по умолчанию 10 подряд) сторона
  автоматически переключается на REST-опрос и продолжает работать.
* **Сеть не роняет бот**: все `NetworkError`/`ExchangeError` гасятся с
  экспоненциальным backoff; биржа, недоступная на старте, просто исключается
  из сканирования (остальные работают).
* **Анти-спам**: кулдаун на валютную пару (по умолчанию 15 минут), лимит
  сообщений за цикл, короткий retry-кулдаун при сбоях Telegram.
* **Автообновление рынков** раз в 12 часов — делистинги и листинги
  подхватываются сами, тысячи подписок пересчитываются без рестарта.

## 🚀 Деплой на Railway

1. Создайте сервис на Railway из этого репозитория (GitHub → New Service).
   Railway сам обнаружит `Dockerfile` (приоритет) и соберёт образ;
   `railway.json` задаёт `startCommand` и политику перезапуска `ALWAYS`.
2. В **Variables** добавьте:
   ```
   TELEGRAM_BOT_TOKEN = <токен от @BotFather>
   CHAT_ID            = <ваш chat_id, узнать у @userinfobot>
   ```
   Переменные уже добавлены у вас — код просто читает их через `os.getenv()`.
3. Запустите. В логах появится конфигурация, затем строки
   `поток данных активен — ... bid=... / ask=...` — реальные цены с бирж.
4. Напишите боту в Telegram `/start` (или просто любое сообщение) — боты
   не могут писать первыми, пока пользователь не начал диалог.

Тип процесса — **Worker**: бот не открывает порт. Railway может показать
предупреждение «Port not detected» — это нормально, игнорируйте его.

### ⚠️ Гео-блокировки бирж (важно!)

Некоторые биржи блокируют IP датацентров: **Binance** не отдаёт данные с
IP США (Railway по умолчанию хостится в US-регионах), **Bybit/OKX** могут
блокировать отдельные регионы. Это ограничение бирж, а не бага.

Что делает бот: недоступная биржа исключается, сканер продолжает работать
с остальными (об этом будет строка в логе и в стартовом сообщении).

Решения, если нужна конкретная биржа:
* смените регион сервиса на Railway (например, `europe-west`);
* или добавьте переменную `HTTPS_PROXY` с адресом прокси в подходящем
  регионе — код это поддерживает (`aiohttp_trust_env`);
* проверьте доступность заранее: `python check_connection.py`.

## ⚙️ Переменные окружения

### Обязательные

| Переменная | Описание |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен бота от @BotFather |
| `CHAT_ID` | ID чата; можно несколько через запятую (`111,222`) |

### Фильтр сигналов

| Переменная | По умолчанию | Описание |
|---|---|---|
| `MIN_SPREAD_PERCENT` | `2.0` | Мин. чистый спред, %. Альтернативное имя: `MIN_SPREAD` |
| `COOLDOWN_MINUTES` | `15` | Анти-спам: пауза между сигналами по одной паре, мин |
| `SPOT_TAKER_FEE_PERCENT` | `0.1` | Комиссия спота, % |
| `FUTURES_TAKER_FEE_PERCENT` | `0.05` | Комиссия фьючерсов, % |
| `MIN_NOTIONAL_USD` | `0` (выкл.) | Мин. объём на лучшей цене, USDT (фильтр «пустых» стаканов) |
| `MAX_SIGNALS_PER_SCAN` | `5` | Лимит сообщений за один цикл сканирования |
| `ALLOW_SAME_EXCHANGE` | `false` | Разрешить связки «спот+перп на одной бирже» (базис/фандинг) |

### Инструменты и биржи

| Переменная | По умолчанию | Описание |
|---|---|---|
| `SYMBOLS` | — | Явный список пар: `BTC,ETH,SOL`. Пусто — авто |
| `TOP_SYMBOLS` | `0` | **0 = ВСЕ поддерживаемые монеты** (тысячи пар). N>0 — только топ-N по объёму торгов |
| `EXCHANGES` | все 5 | Подмножество: `mexc,bybit,gate,okx,binance` |
| `USE_WEBSOCKET` | `true` | WebSocket (ccxt.pro) с авто-fallback на REST |
| `WS_FAILS_BEFORE_REST_FALLBACK` | `10` | Сколько сбоев WS подряд до перехода на REST |
| `ORDER_BOOK_DEPTH` | `5` | Глубина стакана (REST-запросы и WS-подписки) |
| `REST_POLL_INTERVAL_SECONDS` | `3` | Пауза между кругами REST-опроса |
| `REST_THROTTLE_SECONDS` | `0.05` | Доп. пауза между REST-запросами |
| `BOOK_MAX_AGE_SECONDS` | `45` | Макс. возраст котировки в WS-режиме |

**Замечание о масштабе.** Режим «все монеты» — это тысячи WebSocket-подписок
и заметная нагрузка на CPU/память (в REST-fallback — долгие круги опроса,
допустимый возраст котировок расширяется автоматически, а в сигнале
указывается возраст данных). Если нужен лёгкий режим — задайте
`TOP_SYMBOLS=50` (только самые ликвидные пары).

### Служебные

| Переменная | По умолчанию | Описание |
|---|---|---|
| `SCAN_INTERVAL_SECONDS` | `5` | Период цикла оценки спредов |
| `HEARTBEAT_MINUTES` | `0` (выкл.) | Раз в N мин присылать «я жив» в Telegram |
| `STATUS_LOG_MINUTES` | `10` | Раз в N мин писать статус в лог |
| `RESTART_BACKOFF_SECONDS` | `30` | Пауза перед автоперезапуском |
| `LOG_LEVEL` | `INFO` | `DEBUG`/`INFO`/`WARNING` |

## 💻 Локальный запуск

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env   # вписать TELEGRAM_BOT_TOKEN и CHAT_ID (опционально)

python check_connection.py   # убедиться, что биржи доступны с вашего IP
python main.py               # запуск сканера (Ctrl+C — остановка)
```

Без `TELEGRAM_BOT_TOKEN`/`CHAT_ID` бот работает в режиме **DRY-RUN**:
сигналы печатаются в консоль, ничего не отправляется.

### Тесты

```bash
python -m unittest discover -s tests -v
```

47 тестов офлайн (сеть не нужна): формула спреда, все фильтры, кулдаун,
маршрутизация команд Telegram, режим «все монеты», деградация WS→REST.

- **Профит:** сразу в $ для разных депозитов
- **План:** что нажать, какое плечо, как хеджировать
- **Риски и подсказки:** funding, ликвидность, следующие команды

## 📝 Что не учитывается в сигнале (честные ограничения)

* **Ставки финансирования (funding)** перпетуалов — при удержании позиции
  она может как платить вам, так и списывать средства.
* **Проскальзывание** при исполнении и **минимальные лоты** контрактов.
